# Firmware

У наборі SMD Solder Kit немає мікроконтролера тому файл із прошивкою відсутній.

Такт задає таймер на місці U1. Дві мікросхеми на місцях U2 і U3 крокують по світлодіодах. Після пайки USB Type-C подає 5 В, і LED секції світиться, якщо монтаж правильний. Порядок кроків — у `docs/02-getting-started.md`.
