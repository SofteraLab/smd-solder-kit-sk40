# Firmware

У SMD Solder Kit немає мікроконтролера і немає прошивки.

Такт задає таймер 555 на місці U1. Дві мікросхеми 4017 на місцях U2 і U3 крокують по світлодіодах. Після пайки USB Type-C подає 5 В, і LED секції світиться, якщо монтаж правильний. Порядок кроків — у `docs/02-getting-started.md`.
