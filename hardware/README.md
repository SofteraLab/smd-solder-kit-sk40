# Hardware

Виробничі файли SMD Solder Kit — **інтелектуальна власність Softera Lab**.

Ця папка в локальній робочій копії може містити KiCad, Gerber, PDF і BOM для внутрішньої роботи.  
**Не викладайте** ці файли в публічний репозиторій GitHub, якщо мета — продаж набору, а не відкрите залізо.

Публічно достатньо:

- фото і маркетингових карток;
- інструкції збірки для покупця;
- загального опису без повної схеми для виробництва.
